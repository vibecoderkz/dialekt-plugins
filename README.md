# Dialekt plugins

Plugins for Claude Code and Codex from Dialekt.

## dialekt-host

Publish what your AI agent builds to your own address, `https://<name>.dialektai.org`. No CLI, DNS or configuration: register, create a token, paste it into the plugin, and ask your agent to "publish this site".

Setup and usage: [plugins/dialekt-host/README.md](plugins/dialekt-host/README.md)

```
/plugin marketplace add vibecoderkz/dialekt-plugins
/plugin install dialekt-host
```

Service: https://host.dialektai.org
