# Dialekt plugins

Plugins for Claude Code, Claude Desktop and Codex from Dialekt.

## dialekt-host

Publish what your AI agent builds to your own address, `https://<name>.dialektai.org`. No CLI, DNS or configuration: install the plugin, press Connect, sign in in the browser, and ask your agent to "publish this site".

Setup, examples and the data it sends: [plugins/dialekt-host/README.md](plugins/dialekt-host/README.md)

```
/plugin marketplace add vibecoderkz/dialekt-plugins
/plugin install dialekt-host
```

Codex build (uses an access token): [plugins/dialekt-host-codex](plugins/dialekt-host-codex/README.md)
